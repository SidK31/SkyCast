# Security Policy

## Reporting a vulnerability

Please do not publish credentials, API keys, tokens, or other sensitive information in issues or pull requests.

If you discover a security issue in SkyCast, report it privately to the repository owner rather than opening a public issue.

## Secrets policy

SkyCast is designed to run without client-side API secrets. Do not hard-code API keys or tokens into HTML, CSS, JavaScript, or other tracked files.

If a credential is accidentally exposed, revoke or rotate it immediately and remove the exposure from repository history when appropriate.
